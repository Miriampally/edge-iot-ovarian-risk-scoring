# Software-defined edge IoT for ovarian cancer risk scoring: measurement and simulation code

Code for the study **"Software-Defined Edge IoT Architecture for Low-Latency Ovarian Cancer Risk Scoring: Measured Edge Inference and Simulated Deployment"**.

The study compares running CT risk scoring on an on-site **edge node** with uploading the study to a **cloud** service. It combines
*measured* inputs (edge pipeline time on a CPU-only machine, study sizes, round-trip time, uplink speed) with a *simulation* of clinic visits.
Every number is one of: measured, simulated, or assumed. Cloud inference time (4 s, or 0.5 s) is **assumed**.

> The risk score is an exploratory prognostic model, not a detection or screening tool, and not a medical device. No diagnostic accuracy is claimed.
> De-identification in the simulator is a simplified demonstration, not a certified DICOM profile.

## 1. Reproduce the simulation results (about 2 minutes, no patient data needed)

    pip install -r requirements.txt

    # E1-E5 experiments, tables (RESULTS.md) and figures
    python edge_experiments.py --study-mb 112 --wan-mbps 21.2 --rtt-ms 49.8 \
        --edge-infer-s 6.5 --cloud-infer-s 4 --slow-edge-s 11.2 --out results_typical_112MB

    # 200-visit run with policy check, de-identification and hash-chained audit log
    python visit_pipeline_sim.py --visits 200 --study-mb 112 --wan-mbps 21.2 --rtt-ms 49.8 \
        --edge-infer-s 6.5 --cloud-infer-s 4

    # Study-size analysis and the IEEE-sized figures
    python fig_size_scaling.py
    python paper_figures.py --results results_typical_112MB --out paper_figures

All runs use a fixed seed (1), so you should obtain the same numbers as the files in `results/`.

| Quantity (112 MB study, 21.2 Mbps, 49.8 ms round trip) | Value |
|---|---|
| Edge time to result, median / p95 | 7.6 s / 9.2 s |
| Cloud time to result, median / p95 (200 visits) | 53.9 s / 64.2 s |
| Uplink over 200 visits, edge / cloud | 0.4 GB / 22.4 GB (98.2% saved) |
| Break-even uplink (cloud inference 4 s) | about 440 Mbps |
| Audit chain | verified |

## 2. Measure the inputs on your own hardware

| Script | Purpose |
|---|---|
| `patient_sizes.py` | Size of every patient folder; flags folders that are not patients |
| `measure_inputs.py` | Hardware, study sizes, round-trip time, uplink, and per-study pipeline time; prints a ready-to-run `edge_experiments.py` command |
| `pipeline/my_pipeline.py` | Wrapper that times the whole per-patient risk-score pipeline |

Example (needs the data and the pipeline environment, see sections 3 and 4):

    python measure_inputs.py --skip-network --prefix TCGA- --study-dir "<TCGA-OV folder>" \
        --pick-sizes 30,112,500,1500 --runs 3 --model "pipeline/my_pipeline.py:run_study"

The reported timings used one patient per study size (30, 112, 515 and 1610 MB), three runs each, with a warm file cache.

## 3. The risk-score pipeline (`pipeline/`)

The complete code of the exploratory mask-free CT risk score on TCGA-OV: DICOM conversion, preprocessing,
EfficientNetB0 slice embeddings, Cox analyses, the frozen model and its scoring script.
See `pipeline/README.md` for the run order and `pipeline/ANALYSIS_NOTES.md` for cohort decisions, results and limitations.

    cd pipeline
    pip install -r requirements.txt          # Python 3.11, TensorFlow 2.21
    export OVARIAN_DATA_ROOT=/path/to/data   # Windows: set OVARIAN_DATA_ROOT=D:\data
    export TCGA_OV_DICOM_ROOT=/path/to/TCGA-OV

## 4. Data and what is not included

- **CT images** come from The Cancer Imaging Archive, collection **TCGA-OV** (CC BY 3.0). Download them from TCIA; they are not redistributed here.
  Check TCIA's current data-use and citation requirements before use.
- **Clinical data** come from the Genomic Data Commons (`clinical.tsv`), not included.
- **The frozen model** (`frozen_model/model.joblib`, a Python pickle: load only from a source you trust) is generated by `pipeline/17_freeze_model.py`; it is not included.
- **`patient_series_list.csv`** (patients and DICOM series used) is generated by `pipeline/24_patient_series_list.py`.

References for the data:
- Holback C, Jarosz R, Prior F, Mutch D. The Cancer Genome Atlas Ovarian Cancer Collection (TCGA-OV) (Version 4) [Data set]. The Cancer Imaging Archive; 2016. https://doi.org/10.7937/K9/TCIA.2016.NDO1MDFQ
- Clark K, et al. The Cancer Imaging Archive (TCIA): maintaining and operating a public information repository. J Digit Imaging. 2013;26(6):1045-1057. https://doi.org/10.1007/s10278-013-9622-7

| Path | Contents |
